# Hyper Emu

**Advanced PC Emulation Platform by HYPER Company**

Hyper Emu is an Android application that lets you run Windows (x86_64) applications and games using Wine and Box86/Box64 — built and maintained by **Ramin İbiszade** under the **HYPER Company** brand.

## Installation

1. Download the latest APK from the Releases section
2. Install the APK on your Android device
3. Launch the app and wait for the installation to finish

## Features

- Run Windows PC games and apps on Android
- Steam Library integration
- Epic Games Library integration
- Advanced Wine & Box64 compatibility
- Dark neon theme UI
- Controller and touch input support
